# AI 学习闭环

AI Agent 在这个项目中的角色是教练和研究助手，而不是答案来源。每次使用都应产生可验证的学习产物。

## 学习流程

```text
大纲与教材 → 结构化笔记 → Agent 追问 → 独立作答 → 批改与核验 → 错题复盘
```

## 适合交给 Agent 的任务

- 把章节拆成概念、比较、计算和场景题。
- 根据笔记生成由浅入深的追问。
- 按评分点批改案例答案，指出遗漏和无效表述。
- 检查论文提纲是否回应题目、是否缺少项目证据。
- 聚合同类错题，归纳稳定的错误模式。

## 不应直接交给 Agent 的任务

- 替代教材和官方大纲成为唯一事实来源。
- 在没有项目事实时虚构论文经历或量化结果。
- 直接给出真题答案而不要求独立作答。
- 用流畅表达掩盖无法核验的概念和政策信息。

## Prompt 模板

### 知识追问

```text
你是系统架构设计师考试教练。只根据我提供的笔记出题。
先提出 3 个概念辨析题和 2 个场景题，不要给答案。
等我作答后，按“正确点 / 遗漏点 / 错误点 / 改进答案”批改。
```

### 案例批改

```text
根据题干和参考评分点批改我的答案。
逐项说明是否命中评分点，不因表达流畅而额外给分。
最后给出一版不超过 200 字、适合机考输入的改进答案。
```

## 核验规则

涉及考试政策时回到官方网站，涉及知识定义时回到教材或标准，涉及真题时保留来源与年份。任何无法确认的 AI 结论都标记为“待核验”，不直接进入最终笔记。
