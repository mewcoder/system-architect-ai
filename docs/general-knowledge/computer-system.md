# 计算机系统

计算机系统部分覆盖硬件、操作系统、网络、嵌入式与性能。复习时应把概念题和计算题分开训练。

## 操作系统

重点关注进程与线程、调度、同步互斥、死锁、存储管理和文件系统。

### 死锁必要条件

- 互斥：资源一次只能由一个进程占用。
- 请求与保持：持有资源时继续请求新资源。
- 不可剥夺：已分配资源不能被强制收回。
- 循环等待：进程之间形成资源等待环。

破坏任意一个必要条件即可预防死锁。银行家算法属于避免死锁，而非预防死锁。

### 位示图计算

位示图用一个二进制位表示一个存储块是否空闲。计算步骤：

1. 计算块数：存储容量 ÷ 块大小。
2. 每个块需要 1 bit，得到总 bit 数。
3. 除以 8 转换为 Byte，再换算为 KB。

## 计算机网络

重点关注 OSI/TCP-IP 分层、常见协议、传输介质、网络规划和吞吐量计算。

| 层次 | 典型协议或设备 | 关注点 |
| --- | --- | --- |
| 应用层 | HTTP、DNS、SMTP | 应用服务与数据格式 |
| 传输层 | TCP、UDP | 可靠性、流控、端口 |
| 网络层 | IP、ICMP、路由器 | 寻址与路由 |
| 数据链路层 | Ethernet、交换机 | 帧、MAC、差错检测 |

## 系统性能

性能题先确认单位和统计口径。常见指标包括响应时间、吞吐量、利用率、可靠性与可用性；优化时要先定位瓶颈，不能只看单个部件的峰值能力。
