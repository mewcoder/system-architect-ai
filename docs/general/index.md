## 学习地图

综合知识不是平均分布。参考历年题型，软件工程与系统架构设计通常构成核心，计算机系统、数据库、信息安全等模块提供稳定基础分。

## 学习优先级

| 优先级 | 模块 | 训练重点 |
| --- | --- | --- |
| P0 | 系统架构设计 | 架构风格、质量属性、评估、分布式与微服务 |
| P0 | 软件工程 | 生命周期、需求、UML、设计原则、测试与维护 |
| P1 | 计算机系统 | 操作系统、网络、存储与性能计算 |
| P1 | 数据库与信息安全 | 范式、事务、加密、认证与安全体系 |
| P2 | 标准化、知识产权、数学、英语 | 高频概念与稳定题型 |

> 分值会随考期变化。优先级用于安排学习时间，不代表可以放弃低频模块。

## 建议学习顺序

1. 先学软件工程，建立需求、设计、实现与测试的共同语言。
2. 再学系统架构，把质量属性与架构决策联系起来。
3. 补齐计算机系统、网络、数据库与安全基础。
4. 用真题反向校正笔记深度，删除不产生答题价值的内容。

## 掌握标准

每个考点至少完成四层输出：一句话定义、关键特征、典型场景、一道真题。涉及比较的内容必须形成表格，涉及流程或结构的内容必须能画出简图。
