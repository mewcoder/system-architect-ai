# 计算机系统基础知识

本组知识覆盖计算机系统的基础组成、运行与连接，按复习顺序分为计算机组成原理、嵌入式系统、操作系统、计算机网络和数据库系统。

| 模块 | 主要内容 |
| --- | --- |
| 计算机组成原理 | CPU、指令系统、存储器、总线、输入输出与数据校验 |
| 嵌入式系统 | 嵌入式系统特征、实时性、处理器、软件架构与 AI 芯片 |
| 操作系统 | 进程管理、存储管理、文件管理、设备管理与操作系统基础 |
| 计算机网络 | 网络体系结构、通信协议、网络设备、网络安全与网络应用 |
| 数据库系统 | 数据库基础、关系模型、SQL、事务与数据库设计 |
