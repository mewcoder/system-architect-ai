# 案例分析

案例分析考查把知识用于情境的能力。高分答案通常短而具体，并能与题干中的约束建立对应关系。

## 四步作答法

1. 圈出业务目标、现状问题、约束和质量属性。
2. 判断题目考查的知识模块，不急于写方案。
3. 按评分点列出结论，再逐条结合题干解释。
4. 检查数量要求、术语和是否回答了“为什么”。

## 常见题型

- 架构风格或技术方案选择。
- 质量属性场景与设计策略。
- 数据库、缓存、消息和分布式一致性。
- 微服务拆分、服务治理与容错。
- UML、设计模式和软件工程过程。

## 复盘模板

| 项目 | 记录内容 |
| --- | --- |
| 考查模块 | 对应章节与知识点 |
| 题干信号 | 哪些词指向该考点 |
| 标准答案 | 评分点拆分 |
| 我的偏差 | 漏项、误判、表达或时间 |
| 修正动作 | 补笔记、做同类题或重写答案 |
